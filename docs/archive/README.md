## Reglas

- La documentación vigente está un nivel arriba: `README.md`, `docs/VALIDATION_PROTOCOL.md`, `docs/EDGE_FINDINGS.md`, `docs/OTC_FINDINGS.md`, `docs/LIMITATIONS.md`.
- Las rutas de despliegue, nombres de host y topics de notificación que aparecen aquí son **ejemplos de despliegue**, no valores del repositorio.
- Ningún documento de archivo autoriza a operar con dinero real ni a promover una estrategia.
- Si un documento histórico contradice el protocolo vigente, prevalece `docs/VALIDATION_PROTOCOL.md`.
